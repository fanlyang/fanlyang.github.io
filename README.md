# Fan Yang — Academic Pages

Academic Pages theme hosted on GitHub Pages, configured through Jekyll. Theme source: https://github.com/academicpages/academicpages.github.io (pinned to c77da751a8124450d5fb818056c0cf081fea08e1).

Edit the content in index.html, research.html, publications.html, professional.html, and skills.html. Navigation is in _data/navigation.yml and the profile sidebar is in _config.yml. The CV links directly to CV_Fan_Yang.pdf.

The existing repository assets/images directory supplies the portrait and project illustrations. This folder is an update package for the existing repository, not a standalone copy of all image assets.
